# Codie 🤖

**Learn by doing. | Yaparak öğren.**

Codie is a beginner-friendly, browser-based learning platform for exploring the foundations of **Python, HTML, CSS and JavaScript**. Lessons are short and practical, with clear explanations, code examples and quick knowledge checks.

🌐 **Live site:** https://uzimantr.github.io/Codie/

## What is included?

- **Four beginner courses:** Python, HTML, CSS and JavaScript.
- **Guided lessons:** concepts are introduced one step at a time.
- **Code examples:** each lesson includes a copyable example.
- **Quick checks:** short multiple-choice questions give instant feedback.
- **Learning progress:** completed lessons are tracked separately for each course.
- **Two languages:** switch between English and Turkish.
- **Responsive layout:** the learning area adapts to desktop and mobile screens.

## Try it

1. Open the [Codie website](https://uzimantr.github.io/Codie/).
2. Choose a course.
3. Read a lesson and inspect its code example.
4. Answer the quick-check question.
5. Mark the lesson complete and follow your progress.

Progress is saved in the browser's local storage on the current device. There is no account or server-side progress synchronisation.

## Run locally

Open `index.html` in a modern browser. No package installation, build step or framework is required.

## Technology

- HTML
- CSS
- Vanilla JavaScript
- Browser local storage
- GitHub Pages

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
